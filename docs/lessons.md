# Lessons

- Don't take the brand's subject literally. For BSR I built "trash falling + bins" in a cartoon style — user found it banal. A career site must make the job aspirational (cool machines, tech, skill), not illustrate the obvious. Before building: ask "what would make someone *want* this job?" and pitch a concept angle, not just an effect.
- Match visual seriousness to the goal: playful/cartoon flattens a career pitch. Default to premium/industrial unless the user asks for playful.
- "Bis zum Mond" (cinematic 3D, long scroll, lots of facts) was rejected as "слишком нагружено". Keep one idea, one interaction, little text. The user prefers playful + interactive over cinematic storytelling — but the play must serve the career pitch, not just illustrate trash.
- Pixel-art top-down "Kehr-Tour" (drive the truck, collect litter, station cards) — rejected: "не подходит". Four BSR concepts in a row missed. Rule: stop pitching new concepts blind; get a visual reference or a clear "what should it feel like" from the user before building the next one.
