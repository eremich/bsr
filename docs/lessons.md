# Lessons

- Don't take the brand's subject literally. For BSR I built "trash falling + bins" in a cartoon style — user found it banal. A career site must make the job aspirational (cool machines, tech, skill), not illustrate the obvious. Before building: ask "what would make someone *want* this job?" and pitch a concept angle, not just an effect.
- Match visual seriousness to the goal: playful/cartoon flattens a career pitch. Default to premium/industrial unless the user asks for playful.
