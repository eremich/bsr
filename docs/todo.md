# BSR // Kehrwende — концепт карьерного сайта BSR

Идея: сайт, который подметает сам себя. Между сценами проходит вращающаяся щётка уборочной машины (WebGL) и сметает предыдущую сцену.
Тон: тёплый, берлинский, осенний. Ценности BSR: VORANGEhen, #TeamOrange, Null Verschwendung, «Außen orange, innen grün».

## Сцены
- [x] 0 Хиро: осенние 3D-листья, курсор = ветер — «VORANGEhen.»
- [x] Метла 1 (→): сметает листья по-настоящему
- [x] 1 «Außen orange. Innen grün.» — пузырьки биогаза, факт про 190 газовых машин
- [x] Метла 2 (←)
- [x] 2 «Null Verschwendung.» — частицы: бутылка → худи → «0»
- [x] Метла 3 (→)
- [x] 3 «6.400 Menschen. Ein Team.» — 6 400 частиц: «6.400» → сердце
- [x] Метла 4 (←)
- [x] 4 Финал на оранжевом: «Zeit für deine Kehrwende.», бенефиты, «Jetzt bewerben»
- [x] Шапка меняет цвет под фон сцены
- [x] Проверка: десктоп + мобильный 375, консоль без ошибок
